# Fibonacci Number

## Question
The <b>Fibonacci numbers</b>, commonly denoted `F(n)` form a sequence, called the <b>Fibonacci sequence</b>, such that each number is the sum of the two preceding ones, starting from `0` and `1`. That is,

`
F(0) = 0, F(1) = 1
F(n) = F(n - 1) + F(n - 2), for n > 1.
`

Given `n`, calculate `F(n)`.

 

>[!Example]+ Example 1
>**Input**: `n = 2`
>**Output**: `1`
>**Explanation**:
>F(
> 2) = F(
> 1) + F(
> 0) = 1 + 0 = 1. 

>[!Example]+ Example 2
>**Input**: `n = 3`
>**Output**: `2`
>**Explanation**:
>F(
> 3) = F(
> 2) + F(
> 1) = 1 + 1 = 2. 

>[!Example]+ Example 3
>**Input**: `n = 4`
>**Output**: `3`
>**Explanation**:
>F(
> 4) = F(
> 3) + F(
> 2) = 2 + 1 = 3. 

>[!warning]+ Constraints
>- `0 <= n <= 30`

```cpp
class Solution {
 public:
  int fib(int n) {
    if (n == 1 || n == 0)
      return n;
    else {
      int prev2 = 0;
      int prev1 = 1;
      int curr = -1;
      for (int i = 2; i <= n; i++) {
        curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
      }
      return curr;
    }
  }
};
```
